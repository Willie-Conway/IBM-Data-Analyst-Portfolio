SQLite with Python

Python code examples for working with SQLite databases.

Basic SQLite Operations
import sqlite3 import pandas as pd # Create connection and cursor con = sqlite3.connect("INSTRUCTOR.db") cursor_obj = con.cursor() # Create table cursor_obj.execute('''CREATE TABLE IF NOT EXISTS INSTRUCTOR ( id INT PRIMARY KEY, first_name VARCHAR(20), last_name VARCHAR(20))''') # Insert data cursor_obj.execute('''INSERT INTO INSTRUCTOR VALUES (1, 'Rav', 'Ahuja')''') con.commit() # Query data cursor_obj.execute('SELECT * FROM INSTRUCTOR') output_all = cursor_obj.fetchall() # All rows output_many = cursor_obj.fetchmany(2) # First 2 rows # Close connection con.close()
Pandas Integration with SQLite
import pandas as pd import sqlite3 # Read SQL query into DataFrame con = sqlite3.connect("INSTRUCTOR.db") df = pd.read_sql_query("SELECT * FROM INSTRUCTOR", con) print("DataFrame shape:", df.shape) # Write DataFrame to SQL table df.to_sql("new_table", con, if_exists='replace', index=False) con.close()

DB2 with Python

Python code examples for connecting to and working with IBM DB2 databases.

DB2 Connection and Basic Operations
import ibm_db # Connection string for DB2 conn = ibm_db.connect( 'DATABASE=mydb;' 'HOST=hostname;' 'PORT=50000;' 'UID=username;' 'PWD=password;', '', '' ) # Get server information if conn: server = ibm_db.server_info(conn) print(f"DBMS: {server.DBMS_NAME}, Version: {server.DBMS_VER}") # Execute SQL statement sql = "CREATE TABLE instructor (id INT, name VARCHAR(50))" stmt = ibm_db.exec_immediate(conn, sql) # Close connection ibm_db.close(conn)

SQL Joins

Different types of SQL joins for combining data from multiple tables.

Join Type Syntax Description
INNER JOIN SELECT ... FROM table1 INNER JOIN table2 ON condition Returns matching rows from both tables
LEFT JOIN SELECT ... FROM table1 LEFT JOIN table2 ON condition Returns all rows from left table, matched rows from right
RIGHT JOIN SELECT ... FROM table1 RIGHT JOIN table2 ON condition Returns all rows from right table, matched rows from left
FULL OUTER JOIN SELECT ... FROM table1 FULL OUTER JOIN table2 ON condition Returns all rows when there's a match in either table
CROSS JOIN SELECT ... FROM table1 CROSS JOIN table2 Returns Cartesian product of both tables
Join Example
-- Join employees with departments SELECT E.emp_id, E.f_name, D.dept_name FROM employees E INNER JOIN departments D ON E.dep_id = D.dept_id WHERE E.salary > 50000 ORDER BY E.f_name;
